# 이집사 — 이 집 문의하기

유튜브 "이집사" 영상에서 소개한 집에 대해 문의를 받는 페이지입니다.
빌드 도구 없이 정적 파일로만 동작합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 문의 폼 + 접수 완료 화면 |
| `privacy.html` | 개인정보 수집·이용 동의 전문 / 취급방침 |
| `houses.js` | 집 번호 → 집 이름 카탈로그 (영상마다 여기에 추가) |
| `script.js` | 집 코드 처리, 연락처 포맷, 검증, 접수, 완료 화면 |
| `styles.css` | 스타일 |

## 집 코드 링크 규칙

영상 설명란 링크에 집 번호를 파라미터로 답니다. **집 번호는 사용자가 입력하지 않습니다.**

```
https://leejipsa.com/ask?h=034
```

폼 상단에 `문의하시는 집 · 034번 · 김포 32평 모듈러` 처럼 읽기 전용으로 표시되고,
접수 데이터에 `houseCode` / `houseName`으로 기록됩니다.

집 이름은 `houses.js`에서 가져옵니다. 영상을 올릴 때마다 한 줄 추가하세요.

```js
window.LEEJIPSA_HOUSES = {
  "034": "김포 32평 모듈러",
};
```

- 카탈로그에 없는 번호로 들어오면 `034번 집`으로만 표시됩니다.
- 파라미터가 없으면 집 블록 자체가 나오지 않습니다. (문의는 그대로 접수)

## 접수 항목

| 항목 | 필수 | 비고 |
|---|---|---|
| 집 코드 / 이름 | - | URL 파라미터로 자동 기록 |
| 이름 | O | |
| 연락처 | O | `type="tel"` + `inputmode="numeric"`, 자동 하이픈 |
| 관심 있는 부분 | O | 가격 / 시공사 연결 / 비슷한 집 추천 — **복수 선택** |
| 예산대 | - | 선택 |
| 희망 지역 | - | 선택 |
| 궁금한 점 | - | 자유 입력 |
| 개인정보 동의 | O | 옆에 전문 보기 링크 |

접수되면 `LJ-260902-4821` 형식의 접수번호와 함께 완료 화면이 뜹니다.
