# 이집사 — 이 집 문의하기

유튜브 "이집사" 영상에서 소개한 집에 대해 문의를 받는 단일 페이지 폼입니다.
정적 파일 3개(`index.html`, `styles.css`, `script.js`)로만 동작합니다.

## 집 코드 링크 규칙

영상 설명란 링크에 집 번호를 파라미터로 달아두면, 문의가 들어올 때
"몇 번 집 문의"인지 자동으로 기록됩니다.

```
https://leejipsa.com/ask?h=034
```

- `?h=` (또는 `?house=`) 값이 있으면 상단에 `#034`로 표시되고 `houseCode`로 접수됩니다.
- 파라미터가 없으면 "집 번호" 직접 입력 칸이 대신 노출됩니다. (비워둬도 접수 가능)

## 접수 항목

| 항목 | 필수 | 비고 |
|---|---|---|
| 집 코드 | - | URL 파라미터 자동 기록 / 직접 입력 |
| 연락처 | O | 자동 하이픈, 10자리 이상 검증 |
| 관심 있는 부분 | O | 가격 / 시공사 연결 / 비슷한 집 추천 |
| 예산대 | - | 선택 |
| 희망 지역 | - | 선택 |
| 개인정보 동의 | O | 문의 답변 목적 |
